# Media

Promotional assets. Regenerate with `Tools/capture-media.sh`.

- `demo.gif` (680px) and `demo-small.gif` (520px) — a session going from idle to
  working to blocked and back, recorded from the running app.
- `popover.png`, `settings-*.png`, `onboarding-*.png` — window captures, taken
  with `screencapture -l` so they carry no desktop behind them and composite
  cleanly onto any background.

The session names and directories are demo data. The usage percentages are
whatever the machine reported at capture time.
